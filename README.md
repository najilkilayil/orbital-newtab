# Orbital - New Tab

Oritabl is a webpage that shows how a tab window is created using HTML, CSS and JavaScript. It also shows how customizable the new tab was. The user can see the real time information about date and time and as well as user can directly search to google then connects to the best result!

## Features
- Real time information.
- Search bar
- Search rsults will open in new tab.
